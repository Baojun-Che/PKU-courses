# 二维对流扩散与降阶模型基础代码

本目录初步实现《科学机器学习作业一》问题二的有限体积全阶模型、POD-Galerkin 降阶模型，以及保留常数分量的投影增广 DMD。默认 `40×40` 网格用于快速检查；正式作业的 `dx=dy=0.005` 对应 `200×200` 网格，可通过参数运行。本次交付不包含正式网格的完整实验报告。

## 运行与文件组织

建议 Python 3.10 或以上，在本目录执行：

```powershell
python -m pip install -r requirements.txt
python run_demo.py
python -m pytest -q
```

默认计算至 `T=1.5`，比较阶数 `5、10、20`，每 `0.01` 保存一个快照，图表和数据写入本目录的 `outputs/`。绘图使用非交互后端，无须手动关闭窗口。

核心代码位于 `diffusion2d/`：`problem.py` 管理问题与网格，`fvm.py` 组装和推进全阶系统，`pod.py` 实现投影降阶，`dmd.py` 实现仿射增广 DMD，`_linalg.py` 共用快照 SVD 和数值秩处理。`run_demo.py` 组织实验并保存结果，`tests/` 放置物理通量、降阶公式和实际 CLI 的测试。

## 1. 问题设置与有限体积法

求解

$$
\partial_t c+\partial_x c=D(\partial_{xx}c+\partial_{yy}c),\qquad D=0.01
$$

区域为单位正方形，初值为零，速度固定为 `(1,0)`。单元中心为 `x_i=(i+1/2)dx`、`y_j=(j+1/2)dy`；左侧边界值 `g_j` 在严格满足 `1/3<y_j<2/3` 时为 1，其余为 0。上下周期连接；右侧零扩散通量，对流正常流出。

将状态表示为 `(ny,nx)` 数组，按 C 顺序展开为向量，**x 索引变化最快**。所有快照矩阵均为 `(ndof, nsnapshots)`，每列是一个时刻。

有限体积法以单元平均浓度为未知量；沿正 x、正 y 方向定义总通量。内部 x 面采用正速度迎风对流和中心扩散：

$$
F^x_{i+1/2,j}=c_{i,j}-D\frac{c_{i+1,j}-c_{i,j}}{dx}.
$$

y 面仅含扩散通量：

$$
F^y_{i,j+1/2}=-D\frac{c_{i,j+1}-c_{i,j}}{dy},
$$

其中 y 索引循环。左、右外边界通量为

$$
F^x_{-1/2,j}=g_j-2D\frac{c_{0,j}-g_j}{dx},\qquad
F^x_{nx-1/2,j}=c_{nx-1,j}.
$$

左侧浓度条件位于边界面，距第一个单元中心为 `dx/2`，因此扩散项带因子 2。用各面通量差除以网格宽度得到

$$
\dot c_{i,j}=-\frac{F^x_{i+1/2,j}-F^x_{i-1/2,j}}{dx}
             -\frac{F^y_{i,j+1/2}-F^y_{i,j-1/2}}{dy}.
$$

将其组装为稀疏系统 `dc/dt=A@c+f`。按 `(ny,nx)` 数组布局，边界项只有左侧单元非零：`f_grid[j,0]=(1/dx+2D/dx²)g_j`，然后将 `f_grid` 展开为向量 `f`；周期连接属于 `A`。时间推进使用显式 Euler：`c_next=c+dt*(A@c+f)`，没有构造全阶稠密矩阵。

### 时间步选择

要求 Euler 更新中的系数非负，步长上界由最负的对角元给出：

$$
dt_{limit}=\frac{1}{\max_i(-A_{ii})}
           =\frac{1}{1/dx+3D/dx^2+2D/dy^2}.
$$

这一上界包含左侧边界单元的额外扩散系数。默认最大步长为 `0.8*dt_limit`，再将每个快照间隔等分，使实际步长不超过该上界。

- 默认 `40×40`：`dt_limit=1/120≈0.0083333`，实际每步 `0.005`，共 300 步。
- 正式 `200×200`：`dt_limit=1/2200≈0.00045455`，默认实际每步约 `0.00035714`，共 4200 步。
- `snapshot_interval=0.01` 是**保存间隔**，不是默认积分步长。手动 `--dt` 也是步长上限，内部仍会对齐保存时刻。

正式网格下直接用显式 `dt=0.01` 远超过上述限制，高频误差会被放大，可能出现负浓度、振荡和发散。代码拒绝该配置，而非输出不可信的稳定性实验。隐式格式在这个步长下的稳定性不同，本版本未实现隐式求解器。

## 2. POD-Galerkin

以全阶快照构成 `C=[c(t0),...,c(tN)]`，计算薄 SVD：

$$
C=U\Sigma W^T,\quad V=U[:, :r],\quad c\approx Va.
$$

本版本不减去时间均值，因此无需增加均值修正项。利用 `V.T@V=I` 投影原系统：

$$
\dot a=A_r a+f_r,\quad A_r=V^TAV,\quad f_r=V^Tf,
\qquad a(0)=V^Tc(0).
$$

对系数使用显式 Euler，再以 `V@a` 重构全场。默认复用全阶实际步长，比较不同基底数带来的误差；不能因为矩阵变小就假设更大的显式步长稳定。零初值对应零降阶系数。

累计能量为 `sum(s[:r]²)/sum(s²)`。数值秩阈值为 `eps*max(C.shape)*s[0]`；请求阶数大于数值秩时自动截断并报告实际阶数。全零快照得到零维空间基底，避免能量计算除零。

## 3. 保留常数分量的投影增广 DMD

离散全阶系统含边界强迫，单纯拟合 `c_next=Kc` 无法从零初值产生非零浓度，因此需要增广状态 `[c;1]`。本版本先利用快照 SVD 将浓度降到 `z=V.T@c`，并始终保留常数坐标：

$$
Z_-=[z_0,\ldots,z_{N-1}],\quad Z_+=[z_1,\ldots,z_N],
\qquad X_{aug}=\begin{bmatrix}Z_-\\\mathbf1^T\end{bmatrix}.
$$

用 SVD 最小二乘求解 `[B,b] X_aug≈Z_+`，再构造

$$
K_{aug}=\begin{bmatrix}B&b\\0&1\end{bmatrix}.
$$

最后一行固定，确保常数坐标在多步预测中仍为 1。这里实现的是**受约束的投影增广 DMD**，不是对整个 `[c;1]` 同时做秩截断的无约束 exact DMD。

预测采用 `q_k=K_aug^k q_0`、`c_k=V@q_k[:-1]`。矩阵幂不要求特征向量矩阵可逆，也不需要选择复对数分支。预测时刻必须是训练初始时刻加上快照间隔的非负整数倍；训练快照必须等间隔。

对 `K_aug` 做特征分解：`K_aug w=λw`，得到的是以快照间隔 `Δt` 为单位的**离散**有限维 Koopman 谱近似。物理空间模式为 `V@w[:-1]`。复共轭模式的实部、虚部共同描述实值状态的演化；`λ=1` 来自常数坐标，可携带稳态空间结构。图中模式按初始幅度乘物理模式范数排序，仅用于展示；模式的归一化和复相位并不唯一。

## 输出、接口和验证

默认使用 `0～1.5` 的全部快照训练，并在同一时段计算重构误差，**不是外推或泛化实验**。小网格只是算法检查，不能替代正式分辨率和网格收敛分析。

| 输出 | 内容 |
| --- | --- |
| `fvm.npz` | 全阶快照、时间、坐标及实际子步信息 |
| `pod_r*.npz` | POD 基底、降阶矩阵与边界项、奇异值、能量及重构 |
| `dmd_r*.npz` | 增广算子、特征值、特征向量、物理模式及预测 |
| `metrics.csv` | 四个时刻的绝对 L2、相对 L2、L∞ 误差及浓度极值 |
| `summary.json` | 网格、步长、训练范围及请求/实际阶数 |
| `concentration_t*.png` | 指定时刻 FVM 与各阶 POD、DMD 的浓度对比 |
| `pod_energy.png`、`errors.png` | 快照奇异值/能量、全时段相对误差 |
| `dmd_spectrum_r*.png`、`dmd_modes_r*.png` | 各阶离散谱与主要模式实部/虚部 |

L2 使用单元面积加权：`sqrt(dx*dy*sum((c_rom-c_fvm)²))`，相对误差再除以全阶 L2 范数。零参考且零误差时相对误差记为 0。POD 和 DMD 不保证正性，程序不裁剪其浓度；极值写入 CSV，浓度图使用共同比例显示。

核心调用示例：

```python
from diffusion2d import Problem, assemble_system, solve_fvm
from diffusion2d import fit_pod, solve_pod, fit_dmd, predict_dmd

system = assemble_system(Problem(nx=40, ny=40))
full = solve_fvm(system)
pod = fit_pod(system, full.snapshots, rank=10)
pod_result = solve_pod(pod, full.times, dt=full.dt)
dmd = fit_dmd(full.snapshots, full.times, rank=10)
dmd_result = predict_dmd(dmd, full.times)
```

所有结果使用 `result.times` 和 `result.snapshots`。POD 和 FVM 支持自定义初始向量；DMD 默认从训练第一列初始化。接口中的 DMD `rank` 指浓度空间维数，其增广算子维数为 `effective_rank+1`。

演示 CLI 要求终止时间及输出的作业时刻可被快照间隔整除，否则明确报错；独立 FVM 接口仍支持最后一个不足快照间隔的时间段。`T<1.5` 时只输出已覆盖的作业时刻；若尚未覆盖 `0.2`，则展示终止时刻。

测试独立计算通量差以核对矩阵组装，检查半网格边界、周期连接、质量平衡、零状态、均匀稳态、非负性及步长限制。POD 检查正交性、能量截断和完整基底与全阶积分的一致性；DMD 使用已知仿射系统核对谱、常数坐标、模式和训练范围外的多步预测，并测试秩不足及全零数据。CLI 测试实际运行并读取 NPZ、CSV、JSON 和 PNG。

已运行默认 `40×40` 算例，得到 151 个全阶快照，四个指定时刻的结果均已保存。`T=1.5` 时相对 L2 误差如下（相对于同网格 FVM，不是相对于连续方程精确解）：

## 如何让低阶模型失效：简要讨论

可把扩散系数显著减小，并改变入流位置或方向，形成训练时未见过的移动尖锐前沿。平移的窄峰通常需要较多固定 POD 基底表示；少量旧基底会遗漏新结构。对未重新训练的固定 DMD 模型，改变速度、扩散系数或采用复杂时变入流会改变演化规律，原先的单个固定仿射算子不能完整描述新动力学。非线性反应项也可能需要更丰富的观测量。这些变化可能让固定低阶近似明显退化，不表示任意阶数或重新训练后的方法必然失败。
